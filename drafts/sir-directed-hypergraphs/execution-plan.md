## 2. 周计划

### 第 1 周　C1 的立身之本：均场 vs 边基对照

这是新增的、也是最该先做的一周。**先做它是因为：如果边基相对均场的增益在阈值邻域小到测不出来，C1 就不成立，整篇论文的骨架要重搭——这个风险必须最早暴露。**

- 实现 [li2024directed] 式的均场基线（按超度分类的房室方程），作为对照组；
- 实现有向超图上的精确 Gillespie 仿真（大纲 III.4 步骤 1），作为真值；
- 在阈值邻域扫参，出第一张图：**均场误差 vs 边基误差 vs $N$**。

> **早停判据：** 若边基在阈值邻域的误差改善不足一个量级，立即停下来重新评估 C1 的措辞与全文骨架，不要继续往下推。

### 第 2 周　两套理论的推导（可并行）

- **方程侧**：并发型 EBCM 的 $\tau=1,2$ 手推与闭合（大纲 III.2–III.3），标出闭合引入误差的位置；
- **渗流侧**：SIR→有向超图渗流映射的等价性论证 + PGF 自洽方程 + 阈值条件（IV.1–IV.3）。$\alpha^{ab}$ 按 `alpha-definition.md` §3 作为四通道转移算子 $\mathcal{M}$ 的权重进入，阈值即 $\rho(\mathcal{M})=1$；
- 顺带起草 IV.4 的 k-core 双声明。

### 第 3 周　V.4：α 扫描（按新定义重新实现）

**不要照大纲原方案写。** 保度约束下四通道重叠总量被度序列锁死，调节手柄是重叠对数 $m_{ab}$：

- 实现条件均值形式的 $\alpha^{ab}$ 测量；
- 实现以 $m_{ab}$ 为目标的保度双边交换（Metropolis，能量取 `part1-introduction.md` I.2 中的形式）；
- 验证：保度严格成立、命中目标 $\alpha$、且 $\alpha^{\parallel}$ 被固定住；
- 同时实现 $\alpha^{\rightleftarrows}$（Lotito strong 互惠档）的测量——注意它是超边级判据，与张量分量不同类。

### 第 4 周　V.5：方向对称性破缺（按宇称定理重新设计）

- **序参量必须取爆发概率 $\Pi$ 与条件爆发规模 $\bar S$，不能取 $\langle S\rangle$**——命题 2 说明 $\langle S\rangle$ 在逐对独立传播下对任意结构不变；超边级激活破坏其假设 (ii)，预跑测得残余约 $-2\%$（$5.05\sigma$），仍比 $\Pi$ 的破缺幅度（$20.7\sigma$）小一个多数量级。用 $\langle S\rangle$ 做主实验等于把一个二十倍的信号换成一个百分之二的残余；
- **主实验改为驱动分支结构的不对称**（阶数 $\tau\neq\eta$、双度序列不对称）——预跑确认这是破缺的实际来源，$\Delta\alpha$ 不是；
- **$\Delta\alpha$ 降为上界测量**：在互换对称序列上扫 $\Delta\alpha$，报告 $|\mathrm{d}\Pi|$ 的置信上界。这是一个有内容的负面结果——它说明宇称分类只给候选集合，不能预测哪一个真正起作用；
- 同时报告 $\langle S\rangle$ 的**残余不对称**（预跑测得约 $-2\%$，$5\sigma$，源于超边级激活破坏命题 2 的假设 (ii)）——它不是零，须作为已知系统项与 $\Pi$ 的破缺幅度并列；**补偿关系须按全期望公式 $\langle S\rangle=\Pi\bar S+(1-\Pi)s_<$ 逐项核算**——预跑实测自限爆发项在 $\lambda=\lambda_c$ 处占 $\langle S\rangle$ 的 47%，简化成 $\langle S\rangle\approx\Pi\bar S$ 会在最需要它的阈值邻域失效；
- 作为阴性对照：在同一设定下扫 $r_{io}$，验证 $\Pi$ 不破缺——**注意对照必须做在 $\Pi$ 上，做在 $\langle S\rangle$ 上则毫无信息量**；
- **设计简化（预跑确认）**：$\alpha^{\parallel}$ 是 $\mathcal{R}$-偶的，成对 H-vs-$\mathcal{R}$H 比较不受其漂移干扰，故不需要钉住 $\alpha^{\parallel}$；
- **$S_{\rm cut}$**：阈值邻域用 $S_{\rm cut}=0.02$ 已足够干净（$N=400$ 预跑），深超临界区双峰间隙才变脏；生产运行仍建议 $N\ge10^3$ 并报告对 $S_{\rm cut}$ 的敏感性；
- 附录 D 的后向张量算子定义（宇称即 $\mathcal{M}\mapsto J\mathcal{M}^{\top}J$ 下的不变性）。

### 第 5 周　C5：μ→0 桥接 + C3 配套

- 从 III.2 与 IV.2 的自洽方程分别取 $\mu\to0$，逐项对照证明同构；**端点已数值验证**：$\lambda=500$ 时 Gillespie 终态与确定性可达集逐种子完全一致（150 个种子最大偏差 0.0000，见 `tools/feasibility_check.py`），两方法的共同极限存在且已知；
