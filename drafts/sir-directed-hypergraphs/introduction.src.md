# I. 引言

在成对接触网络上，SIR 传播的理论已沿两条互相独立的路径发展成熟。终态一侧由渗流承担：度分布的异质性把爆发阈值压向零 \cite{pastorsatorras2001}，随机图的连通结构可由生成函数一次解出 \cite{newman2001random}，而键渗流映射把最终感染规模化归为占据概率 $\phi$ 下的巨簇规模 \cite{newman2002spread}。这一映射在传染期分布异质时失效，其适用边界由 Kenah 与 Robins 厘清 \cite{kenah2007}，根源可上溯至一般流行过程与动力学渗流的等价性 \cite{grassberger1983}。含时一侧由方程法承担：Volz 用成对近似给出随机网络上 SIR 的低维闭合 \cite{volz2008}，Miller 等将其整理为边基房室模型（EBCM），以"沿一条边尚未传来感染"的概率作为唯一闭合变量复现整条流行曲线 \cite{miller2012ebcm}，并可容纳非指数康复——后者会显著移动阈值 \cite{vanmieghem2013}。两条路径分工明确：渗流给出阈值与终态，方程给出峰值与时间演化，二者的交叉验证是网络传播理论可信度的主要来源 \cite{pastorsatorras2015}。

方向性早已进入这一框架。有向随机图的巨强连通分支由入出度联合生成函数决定 \cite{dorogovtsev2001giant}，广义有向渗流给出 in-component 与 out-component 的完整刻画 \cite{boguna2005directed}，并已直接用于有向接触网络上的流行预测 \cite{meyers2006directed}。更重要的是，入出度相关性本身即是一个动力学量：在有向成对网络上，正的入出度相关使系统对传染更稳健，负相关则使其更脆弱 \cite{xu2018directionality}，其机制与无向网络中度—度同配性的作用并不相同 \cite{newman2002assortative}。

与此同时，传播研究的重心转向高阶交互——许多传染并非沿边逐个发生，而是在一个群体内一次性发生 \cite{battiston2020,battiston2021}。群体强化可把连续相变变为不连续相变并带来滞后 \cite{iacopini2019}；群体规模、群体阈值与非线性感染核已被纳入统一框架 \cite{dearruda2020,stonge2021prl}，并与经典的阈值型复杂传播接轨 \cite{watts2002,centola2007}；度与超边基数的异质性可定性改变相变类型 \cite{landry2020}，并决定哪些群体最适合作为种子 \cite{stonge2022}；超核与高阶连通分支决定局域化与传播命运 \cite{mancastroppa2023,kim2024components}。尤为关键的是，超边之间的重叠被证明决定了转变是否爆炸式，且方向与直觉相反：低阶内重叠才导致爆炸性与双稳 \cite{malizia2025overlap}。这一组织可整理为一个超边重叠矩阵，其对角元与非对角元分别对应阶内与阶间重叠 \cite{lamataotin2025matrix}，而阶间相关驱动系统沿不同路径走向爆炸式传播 \cite{malizia2025gbcm}。渗流一侧亦已建立 \cite{bianconi2024percolation,sun2021multiplex}，相关进展见综述 \cite{dearruda2024review}。这些工作共享同一前提：超边是无向的，一条超边内的所有节点对称地相互施加影响。

然而现实中的高阶交互往往不对称。代谢与化学反应由底物集指向产物集 \cite{klamt2009}，一组作者引用一组文献同样是尾集指向头集的 \cite{benson2018}，而有向超图作为数据结构在算法领域已有三十余年历史 \cite{gallo1993}。其结构侧近年被迅速补齐：真实有向超图的微观组织、高阶互惠性与 motif 已被系统刻画 \cite{lotito2026directed,kim2023reciprocity}，超边重叠的测度与生成器亦已成型 \cite{lee2021overlap}，保入出度序列的均匀采样与非退化零模型均已可用 \cite{chodrow2020,nakajima2022randomizing,kraakman2026sampling,abuissa2026dinghy}。动力学一侧由 Li 等开启：他们在有向超图上建立社会传播模型，发现不连续相变的双稳区间随有向强度减弱而收缩，从而确立了方向性确实改变高阶传播相变结构这一事实 \cite{li2024directed}。该工作采用按超度分类的均场闭合，不涉及渗流，其方向性由单一标量强度参数调节。均场忽略邻域相关，误差在阈值邻域最大；在成对网络上，正是 EBCM 补上了这一层 \cite{volz2008,miller2012ebcm}。因此，有向超图上传播的阈值究竟如何依赖于结构相关，目前既缺少超出均场的含时理论，也缺少可用于解析扫描的渗流理论。

本文沿两条互相独立的路径推进这一问题，并证明二者在同一极限下相合。第一条是方程法：我们提出有向超图 SIR 的并发型 EBCM 方程。其技术困难在于一个头节点同时承受多条超边、多个尾成员的并发压力，闭合变量不能简单相乘；我们给出闭合方案，在 $\tau=1,2$ 手推验证，并以精确 Gillespie 仿真 \cite{gillespie1977} 在阈值邻域校验，从而定量给出边基闭合相对均场的增益。第二条是渗流法：我们把成对网络上成熟的 SIR–渗流映射 \cite{newman2002spread,kenah2007} 与有向渗流的生成函数机制 \cite{boguna2005directed,dorogovtsev2001giant} 推广到有向超图，得到爆发阈值随结构参数变化的半解析依赖。两条路径互不依赖，因而可互为验证；我们进一步证明二者的自洽方程在 $\mu\to0$ 极限下同构，给出同一阈值。

为使结构依赖可被受控地检验，我们给出有向超边重叠的可计算定义：对每一对有序超边构造 $2\times2$ 重叠列联矩阵，其四个通道分别对应共发、共收与两个方向的串联，按阶聚合后即为一个张量，其阶对角块与非对角块分别退化为已有的阶内与阶间重叠 \cite{malizia2025overlap,lamataotin2025matrix}。四通道求和逐超边对地精确回收无向定义，因此本文结果可与无向情形直接对照。互惠通道则直接采用文献中的强互惠判据 \cite{lotito2026directed}。在此定义下，我们在严格保持逐节点入出度的约束下运行以入出度相关 $r_{io}$ 与重叠 $\alpha$ 为目标的定向重连，从而沿单一结构坐标扫描，而非事后观测；零模型基线取自已有的均匀采样器 \cite{kraakman2026sampling,abuissa2026dinghy}。

由此得到的一个结果与直觉相反，值得在此提前指出。全局方向翻转 $\mathcal{R}$ 是结构空间上的对合；若生成系综在 $\mathcal{R}$ 下不变，则系综平均的爆发规模必然对称。因此方向对称性破缺要求某个 $\mathcal{R}$-奇不变量非零。而入出度相关 $r_{io}$ 在 $\mathcal{R}$ 下是偶的——方向翻转互换每个节点的入度与出度，而相关系数对其两个变量对称。这意味着单独调节 $r_{io}$ 不可能产生系综层面的方向不对称，尽管它确实移动阈值。破缺的最低阶来源是共发与共收重叠之差 $\Delta\alpha$。我们据此设计破缺实验，并给出 $r_{io}$ 扫描下无破缺的阴性对照。

需要说明的是，当群体阈值 $\theta\ge2$ 时，模型落入 bootstrap 与 $k$-core 型渗流，其阈值与相变级数均不同于普通渗流 \cite{dorogovtsev2006kcore,baxter2010bootstrap}；本文对 $\theta=1$ 与 $\theta\ge2$ 分别给出结论，二者不可混用。

本文余下部分安排如下。第 II 节给出有向超图与 SIR 动力学的定义，以及有向超边重叠的可计算形式。第 III 节推导并发型 EBCM 方程并给出仿真校验。第 IV 节建立 SIR 到有向超图渗流的映射与生成函数阈值理论。第 V 节介绍保度生成与定向重连工具。第 VI 节给出阈值对结构参数的依赖、方向对称性破缺及两方法的交叉验证。第 VII 节以真实有向超图数据佐证。第 VIII 节讨论与结论。
