## I.1 研究背景

### 起点：成对网络上的 SIR 已经有两条成熟路径

在成对接触网络上，SIR 传播的理论框架已相当完备，而且是**双轨**的。

终态一侧由渗流承担。度分布的异质性把爆发阈值压向零 [pastorsatorras2001]；随机图上的连通结构可由生成函数（PGF）一次解出 [newman2001random]；Newman 的键渗流映射进一步把"最终有多少人被感染"化归为"占据概率 $\phi$ 下的巨簇有多大" [newman2002spread]。这一映射的适用边界——传染期分布异质时逐边占据不再独立——随后由 Kenah 与 Robins 厘清 [kenah2007]，其物理根源可上溯到一般流行过程与动力学渗流的等价性 [grassberger1983]。

含时一侧由方程法承担。Volz 用成对近似写出随机网络上 SIR 的低维闭合 [volz2008]，Miller 等将其整理为边基房室模型（EBCM）：以"沿一条边尚未传来感染"的概率作为唯一闭合变量，用少数几个常微分方程复现整条流行曲线，并可容纳非指数康复 [miller2012ebcm]；后者的重要性在于，非马尔可夫的传染/康复期会显著移动阈值 [vanmieghem2013]。

两条路径分工明确、结论互洽：渗流给阈值与终态，方程给峰值与时间演化，二者在成对网络上已被反复交叉验证 [pastorsatorras2015]。**本文要做的，正是把这套双轨结构搬到有向超图上。**

### 方向性在成对网络上已经是一个动力学旋钮

方向性早已进入上述框架。有向随机图的巨强连通分支由入/出度联合 PGF 决定 [dorogovtsev2001giant]；广义有向渗流给出了 in-component 与 out-component 的完整刻画 [boguna2005directed]；Meyers 等把它直接用于有向接触网络上的流行预测 [meyers2006directed]。

更关键的是**入出度相关性本身会移动阈值**：Xu 等在有向成对网络上发现，正的入出度相关使系统对传染更稳健，负相关则使其更脆弱 [xu2018directionality]。这一效应与无向网络中度—度同配性的作用 [newman2002assortative] 机制不同，不能互相替代。也就是说，在成对世界里，"方向"与"入出度相关"都不是记号上的装饰，而是能定量移动爆发阈值的结构自由度。

### 高阶传播进展迅速，但几乎全是无向的

过去数年，传播研究的重心转向高阶交互：许多传染并非沿一条条边逐个发生，而是在一个群体内一次性发生 [battiston2020, battiston2021]。这条线上的结论已经相当丰富：

- 单纯复形上的社会传播中，群体强化可把连续相变变为不连续相变并带来滞后 [iacopini2019]；
- 超图上的传播模型把群体规模、群体阈值与非线性感染核纳入统一框架 [dearruda2020, stonge2021prl]，并与经典的阈值型复杂传播 [watts2002, centola2007] 接轨；
- 度与超边基数的异质性可以定性改变相变类型 [landry2020]，并决定哪些群体最适合作为种子 [stonge2022]；
- 超核（hyper-core）与高阶连通分支被识别为决定局域化与传播命运的结构量 [mancastroppa2023, kim2024components]；
- 超边之间的**重叠**被证明是驱动爆炸式转变的关键结构量 [malizia2025overlap]；
- 渗流一侧亦已建立：超图渗流的一般理论 [bianconi2024percolation]、多重超图上的高阶渗流 [sun2021multiplex]、以及三元相互作用下的动态渗流 [sun2023triadic]。

该领域已有系统综述 [dearruda2024review]。但这些工作**几乎无一例外地共享同一前提：超边是无向的**——一条超边内的所有节点对称地相互施加影响。

### 空白：结构已经有向化，动力学还没有

现实中的高阶交互往往是不对称的。代谢与化学反应网络天然由底物集指向产物集 [klamt2009]；引用与合作数据中，"一组作者引用一组文献"同样是尾→头的 [benson2018]；有向超图作为数据结构在运筹与算法领域已有三十余年历史 [gallo1993]。

真正的转折发生在最近两年——**有向超图的结构侧正在被迅速补齐**：

- 真实有向超图的微观组织（超边指纹、高阶互惠性、有向 motif）已在比特币交易、代谢网络与引用数据上被系统刻画 [lotito2026directed]；
- 谱中心性的有向/异质推广已经展开 [contrerasaso2024beyond]；
- 保持入/出度序列的有向超图均匀采样 [kraakman2026sampling] 与非退化零模型 [abuissa2026dinghy] 已经可用；无向侧的位形模型 [chodrow2020] 与保度保相关随机化 [nakajima2022randomizing] 更早就有；
- 高阶相关性（含时序记忆）的测量工具也已成型 [gallo2024memory]。

结构工具齐了，**动力学理论却还是空的**。据我们检索，尚无工作在有向超图上给出 SIR 的含时方程理论或渗流阈值理论。于是下面两个问题都还没有答案：

> **(Q1)** 尾集 $T(e)$ → 头集 $H(e)$ 的方向性如何进入高阶传播的爆发阈值？
> **(Q2)** 当"入出度相关" $r_{io}$ 与"阶间重叠" $\alpha$——这两个只有在**有向高阶**结构中才能同时存在的自由度——被独立调节时，阈值与终态规模如何响应？

这两个问题不是把已有结果加一个箭头就能回答的。方向性一旦进入，"一条超边内部对称"这一前提失效：尾集的感染状态与头集的易感状态在演化中扮演不同角色，逐边占据概率不再对称，因而成对有向渗流的 in/out-component 分解 [boguna2005directed] 与无向超图渗流的自洽方程 [bianconi2024percolation] 都不能直接搬用。

### 本文的做法与贡献

我们在有向超图上沿两条**互相独立**的路径建立 SIR 理论，并证明二者在同一极限下相合：

- **C1（方程法）** 提出有向超图 SIR 的**并发型 EBCM** 方程。关键困难在于一个头节点同时承受多条超边、多个尾成员的并发压力，闭合变量不能简单相乘；我们给出闭合方案、在 $\tau=1,2$ 手推验证，并用精确 Gillespie 仿真 [gillespie1977] 在阈值邻域校验。
- **C2（渗流法）** 建立 SIR → 有向超图渗流的映射与 PGF 阈值理论，给出阈值随 $r_{io}$、$\alpha$、$(\tau,\eta)$ 与群体阈值 $\theta$ 的（半）解析依赖。
- **C3（数值工具）** 给出**以目标结构量为靶的**严格保度重连工具链：在逐节点 $k_{\rm in},k_{\rm out}$ 完全不变的前提下，把 $r_{io}$ 与 $\alpha^{\rightrightarrows}/\alpha^{\rightleftarrows}$ 调到指定值，从而做受控扫描而非事后观测。
- **C4（现象）** 刻画**方向对称性破缺**：翻转全部超边方向后爆发规模不守恒，并给出机制层面的解释与（拟）判据。
- **C5（统一）** 证明 C1 的自洽方程与 C2 的 PGF 方程在 $\mu\to0$ 极限下同构，因而给出同一阈值——这是本文把两套方法缝合成一篇论文而非两篇论文的技术支点。

## I.2 与已有工作的边界声明

本节的目的只有一个：**逐条划清增量，防止审稿人把本文读成"某已有结果的有向推广"。**

| 对照对象 | 已有工作给了什么 | 本文的增量 |
|---|---|---|
| **无向高阶 SIR/SIS** [iacopini2019, dearruda2020, landry2020, stonge2022, dearruda2024review] | 群体阈值、非线性感染核、异质性导致的相变类型改变——全部在"超边内部对称"前提下 | 引入尾/头分离后，超边内部对称性被打破，产生两个**在无向情形下不存在**的结构自由度：$r_{io}$ 与方向化重叠 $\alpha^{\rightrightarrows}/\alpha^{\rightleftarrows}$ |
| **有向成对网络传播** [meyers2006directed, boguna2005directed, xu2018directionality] | 有向渗流的 in/out-component 分解；入出度相关影响阈值（正相关更稳健） | 加入高阶机制（群体阈值 $\theta$ / 剂量累积）。$r_{io}$ 的效应在 $\theta\ge2$ 时不能由成对结果外推，因为一个头节点是否被感染取决于**多个尾成员的联合状态**，而非单条边 |
| **无向超图渗流** [bianconi2024percolation, sun2021multiplex, sun2023triadic] | 超图渗流的自洽方程与临界性 | 占据规则变为单向（尾→头），自洽方程从单变量变为**入/出双分支耦合**；并给出与之配套的**含时**方程法 |
| **超边重叠驱动的爆炸式转变** [malizia2025overlap] | 超边重叠是驱动不连续转变的关键量（无向） | 把重叠**按方向分解**为同向 $\alpha^{\rightrightarrows}$ 与反向 $\alpha^{\rightleftarrows}$，并指出二者对阈值的作用可以反号——这在无向情形下无从定义 |
| **超图位形模型 / 零模型 / 采样** [chodrow2020, nakajima2022randomizing, kraakman2026sampling, abuissa2026dinghy] | 无向超图的位形模型与保相关随机化；有向超图保入/出度序列的均匀采样与非退化零模型 | 本文的重连**不是**又一个零模型采样器：它是**以 $r_{io}$、$\alpha$ 为目标的定向重连**，用于在保度约束下生成一整条结构扫描线，供动力学实验使用 |
| **有向超图结构刻画** [lotito2026directed, contrerasaso2024beyond] | 真实有向超图的指纹、高阶互惠性、motif、谱中心性 | 从"结构长什么样"推进到"结构如何决定传播阈值"，并把 $r_{io}$、$\alpha$ 这两个可测量量与阈值定量挂钩 |
| **k-core / bootstrap 渗流** [dorogovtsev2006kcore, baxter2010bootstrap, kim2024components] | 阈值型激活的渗流对应 bootstrap/k-core，相变级数与普通渗流不同 | 本文明确给出**双声明**（见 IV.4）：$\theta=1$ 落回普通有向渗流巨簇；$\theta\ge2$ 落入 bootstrap/k-core 型，阈值与相变级数不同。二者不可混用 |

**一句话边界：** 已有工作分别解决了"高阶但无向"的传播、"有向但成对"的传播、以及"有向超图的静态结构"；本文补的是三者的交集——**有向超图上的传播动力学**——并同时给出含时与终态两套互为验证的理论。

## 待办与风险（写作侧）

以下三点会影响 I.1/I.2 的最终措辞，需在定稿前处理：

1. **$\alpha$ 的定义未定（大纲风险 2.2）。** 上表中"把重叠按方向分解"这一增量声明，目前是**方向性的承诺而非已完成的定义**。$\alpha^{\rightrightarrows}/\alpha^{\rightleftarrows}$ 的可计算式（尾集内部两两节点方向的投影方式）定死之前，这一格只能这样写；定死之后应替换为精确表述。

2. **C3 的表述必须收窄。** 大纲原文写的是"提出严格保度的有向超图生成/重连工具链"。这个表述已被文献超越：Kraakman & Stegehuis [kraakman2026sampling] 给出了固定度的有向超图均匀采样，Abuissa 等 [abuissa2026dinghy] 给出了非退化有向超图零模型，Nakajima 等 [nakajima2022randomizing] 更早给出了保度保相关的无向超图随机化。**"我们做了保度重连器"不能作为贡献声明**；能站住的是"以 $r_{io}$/$\alpha$ 为靶的定向重连 + 用它做受控动力学扫描"。上文 C3 与边界表已按此收窄，建议正文与摘要同步改口径。

3. **新颖性声明需最后一次全库扫描。** "尚无工作在有向超图上给出 SIR 方程/渗流理论"这一断言，本轮通过 CrossRef 全量检索 + 网络检索得到支持，但 Semantic Scholar 与 OpenAlex 在核验时触发限流（HTTP 429），未能做完整交叉确认。投稿前应重跑一次三库检索，并把 arXiv 近半年预印本纳入。目前正文已使用"据我们检索"的措辞，风险可控。
