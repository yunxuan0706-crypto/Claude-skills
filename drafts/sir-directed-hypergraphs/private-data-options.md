# 用私有数据的话，选哪些

> 对应大纲 1.1（真实数据）· 第 VII 部分
> 前提：目标期刊已定为物理刊，短工期路线

---

## 0. 先说一件会改变期刊选择的事

用私有数据，**PRE 与 Communications Physics 的风险差别很大**：

| | Physical Review E（APS） | Communications Physics（Springer Nature） |
|---|---|---|
| 数据可得性声明 | 强制，从预设选项中选一条 | 强制，须随稿提交 |
| 数据不能公开时 | 须给出理由，并同意应要求向编辑/审稿人私下共享 | 须在投稿时向编辑披露全部限制 |
| 对录用的影响 | **明确声明：只要满足上述两条，是否公开共享数据不影响录用决定** | **编辑保留权利：若认为限制"过度妨碍"，可直接拒稿** |

**结论：若第 VII 部分用私有数据，优先投 PRE。** APS 的政策把"不公开"明确排除在录用判据之外，Springer Nature 则把它留成编辑的自由裁量。这一条足以在两刊之间做决定——而你之前倾向的 Communications Physics 恰好是风险更高的那个（还叠加了 [li2024directed] 同刊、审稿人可能是原作者组的风险）。

> 另需注意：两刊都要求**能向审稿人提供数据**。如果私有数据连审稿人都不能看（涉密、合规禁止），那不是"投哪家"的问题，而是这份数据不能用来支撑论文的核心主张——只能降级为定性佐证。

## 1. 本文对数据的硬性要求

不是任何有向超图都能撑起第 VII 部分。按模型倒推，四条硬要求：

1. **尾/头语义必须是"影响的施加方向"，不能只是"关系的方向"。** SIR 的语义是尾集感染 → 对头集施压。数据里的箭头必须能读成这个意思，否则整章是错配。
2. **重叠必须非平凡。** 四通道 $\alpha$ 是 VI.1/VI.2 的主轴。若数据近似树状、超边之间几乎不共享节点，$\alpha$ 全为零，核心结果没有数据支撑。**这是筛选第一关。**
3. **$\tau>1$ 且 $\eta>1$（至少尾侧要大于 1）。** 若 $\tau=1$（单一发送方），模型退化为 III.3 的 sanity-check 情形，高阶卖点被削掉一半。
4. **$\Delta\alpha=\tfrac12(\alpha^{TT}-\alpha^{HH})\neq0$。** 这是方向对称性破缺（C4）唯一的实测抓手。若数据里共发与共收重叠恰好相当，破缺一章没有真实数据可对照。

规模上：节点数 $10^3$–$10^4$ 量级即可（生成器自检用的是 $N=3000$），超边数不宜少于节点数。

## 2. 私有数据类型排序

### A 档：代谢 / 化学反应网络　**最推荐**

反应即"底物集 → 产物集"，天然是有向超边，且 $\tau>1$、$\eta>1$ 同时成立。

**为什么它比其他选项好一档：群体阈值 $\theta$ 在这里有真实的物理对应。** 一个反应要发生，所有底物必须齐备——这就是一个 AND 门，即 $\theta=\tau$。本文的群体阈值机制在别的数据里都是类比，只有在这里是字面意义上的机制。这一点值得在正文里明说。

- 私有来源：实验室自建的未发表菌株/物种代谢重建模型、企业代谢工程模型、机构授权的商业数据库版本
- 传统衔接：[klamt2009] 已确立代谢网络的超图表示，物理刊读者认这条线
- 重叠丰富：共享代谢物极多，四通道 $\alpha$ 都非平凡

> **一个必须处理的坑：** ATP、NAD(H)、H₂O、H⁺、CoA 这类 currency metabolite 参与几乎所有反应，会完全支配重叠统计——不剔除的话 $\alpha$ 测的其实是"有多少反应用 ATP"。剔除是该领域标准操作，但**必须在正文写清剔除清单与敏感性检查**，否则审稿人第一条意见就是这个。

### B 档：多方交易 / 供应链

供应商集 → 采购方集；或多输入多输出的资金流转。$\tau>1$、$\eta>1$ 自然成立。

**对 C4 特别有价值**：上游集中、下游分散是这类系统的常态，因此 $\alpha^{TT}\neq\alpha^{HH}$ 很可能显著，$\Delta\alpha\neq0$ 有真实来源——这正是破缺实验需要的。

- 私有来源：企业 ERP、机构采购记录、银行流水
- **最大风险是合规**：这类数据往往连审稿人都不能看，会直接撞上 §0 的红线。落地前先确认能否向审稿人提供脱敏版本。

### C 档：邮件 / 群消息

发件人 → 收件人集，方向语义干净，剂量累积（同一人被多个来源反复触达）的故事也自然。

**但通常 $\tau=1$**，违反硬要求 3，退化为高阶只在头侧的情形。可以用，但会削弱高阶卖点，且隐私敏感度高。若采用，建议只作为**补充案例**而非主案例。

### D 档：引用 / 合作 / 代码评审　**不建议作主案例**

引用数据虽然能构造成"一组作者 → 一组被引文献"，但**方向语义是"引用"，不是"影响的传播"**——被引文献不会因为被引而"被感染"。硬要套 SIR 语义会被审稿人质疑。代码评审（PR 作者 → 评审人集）同样多为 $\tau=1$。

> 注意：[lotito2026directed] 用了引用数据，但他们做的是**结构刻画**，不涉及动力学语义，所以没有这个问题。我们做传播，就有。

## 3. 可行性筛选清单（一个下午能做完）

拿到任何候选数据，按顺序跑这五步，任一步失败就换数据：

1. **$T\cap H=\varnothing$ 是否成立？** 若有节点同时在尾和头（如自催化反应），需要定一条处理规则（拆分或剔除），并记录影响多少条超边。
2. **阶分布 $(\tau,\eta)$。** 出二维直方图。$\tau=1$ 占比过高 → 降级为 C 档用法。
3. **重叠是否非平凡？** 统计四通道各自的"发生重叠的超边对数" $m_{ab}$ 与条件均值 $\alpha^{ab}$。若某通道 $m_{ab}$ 接近零，该通道的结论无法支撑。
4. **$r_{io}$ 与 $\Delta\alpha$ 是否退化？** 两者都接近零 → 结构扫描没有真实锚点，第 VII 部分只能做定性对照。
5. **与均匀零模型的对比是否有信号？** 用 [kraakman2026sampling] / [abuissa2026dinghy] 的采样器生成保度零模型，看实测 $\alpha$、$r_{io}$ 是否显著偏离。若不偏离，说明这份数据的结构相关性本身就不显著，用它佐证结构效应说服力有限。

## 4. 强烈建议：混合策略，不要只用私有数据

**用一个公开数据集作可复现锚点 + 私有数据作增值案例。**

具体：主案例仍取 [lotito2026directed] 的公开三件套之一（代谢网络那个正好与 A 档同域），私有数据作为第二个案例，展示公开数据上没有的结构区间（例如更极端的 $\Delta\alpha$）。

三个理由：

1. **消除投稿风险。** 数据可得性声明可以写成"主结论所依据的数据已公开可得；补充案例的数据因……受限，可应要求向编辑与审稿人提供"。这个形态两家刊都接受。
2. **结论更可信。** 同一套结构—阈值关系在公开数据与私有数据上都成立，比只在一份别人看不到的数据上成立强得多。审稿人无法验证私有数据，但能验证公开的那份。
3. **抗风险。** 如果私有数据最后拿不到授权、或合规评审卡住、或筛选清单没过，论文不会因此崩——公开锚点已经把第 VII 部分撑住了。这一点在只剩十周的工期下尤其重要。

## 5. 数据可得性声明的写法

若采用混合策略，PRE 提交时可按此起草（投稿前须与实际情况核对）：

> 支撑本文主要结论的有向超图数据集为公开数据，来源见正文与参考文献。第 VII.x 节使用的补充数据集因 \[机构授权 / 商业保密 / 隐私合规\] 不能公开发布；该数据集的脱敏版本可应合理请求向编辑与审稿人提供。用于生成、重连与分析的全部代码已公开于 \[仓库地址\]。

**代码一定要公开。** 数据受限时，公开代码是挽回可复现性的最有效手段，而本文的生成器与重连工具链本身就是可独立使用的产出——公开它对 C3 的可见度也有好处。
