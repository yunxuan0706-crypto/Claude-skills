# Fig. 1 — PowerPoint 施工表

本表对应 `fig1_ppt_reproducible.pptx` / `fig1_ppt_190mm.png`（照着画的目标图）。

**最快的做法**：直接打开 `fig1_ppt_reproducible.pptx`，把里面的形状复制到你自己的幻灯片里再改。本表是给需要从零手画、或要核对精确数值时用的。

## 0. 画布与通用设置

| 项目 | 值 |
|---|---|
| 设计 → 幻灯片大小 → 自定义 | **19.00 cm × 14.50 cm** |
| 字体（全图统一） | **Arial** |
| 单位 | 厘米。表中「X / Y」= 形状外框左上角，填在「设置形状格式 → 大小与属性 → 位置」 |
| 超边、节点 | 插入 → 形状 → **椭圆**（按住 Shift 得正圆） |
| 箭头、分隔线 | 插入 → 形状 → **直线**；箭头在「线条 → 箭头末端类型 → 箭头」 |
| 公式框 | 插入 → 形状 → **圆角矩形** |
| 颜色 | 填充/线条 → 其他颜色 → 自定义 → 十六进制 |
